# Research plan

The benchmark supports review of NSGD and RG on flat and hierarchical synthetic sequences.

Remaining work:
1. Validate hierarchy readout stability over multiple checkpoints and seeds.
2. Separate input, relation, optimizer and upper-level token memory in controlled comparisons.
3. Compare compute budgets explicitly alongside input-step budgets.
4. Test adaptation when the graph structure switches, including return-to-source sequences, before making retention claims.
5. Develop the directed-transition (CI) line into a tested causal-structure method.

These are proposed directions, not completed results.
